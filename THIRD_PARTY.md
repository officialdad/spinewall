# Third-party software

Spinewall bundles none of the items below. `scripts/install.sh` fetches the Spine runtimes on the user's machine. The live demo in `docs/demo/` loads the 4.1.56 player from the jsDelivr npm CDN, pinned with SRI hashes, and never stores it in the repository.

|---|---|---|
| Spine Web Player 3.8 | `EsotericSoftware/spine-runtimes`, commit `8b4844b` | Spine Runtimes License |
| Spine Web Player 4.0, 4.1, 4.2 | npm `@esotericsoftware/spine-player` | Spine Runtimes License |
| `webwallpaper-kde` | `ekoputrapratama/webwallpaper-kde` | Check the project |

Each user needs a Spine Editor license. See [docs/credits.md](docs/credits.md).
