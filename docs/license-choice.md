# License choice

Spinewall uses MIT. Stay with MIT.

| | MIT | Apache-2.0 |
|---|---|---|
| Length | One page | Longer, with a NOTICE duty |
| Patent grant | None written | Explicit grant from each contributor |
| Fit for a small viewer | Yes | Yes |

- The code is small. A patent grant adds little.
- The legal risk sits elsewhere. The Spine Runtimes License governs the runtimes, and game owners hold the art. Neither license changes that.
- Change to Apache-2.0 only if companies will contribute and want the patent grant. The change needs the consent of every contributor, so decide early.
