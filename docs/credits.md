Spinewall ships no Spine runtime. The only models are the few samples for the live demo, under `docs/demo/models/`. Each project below keeps its own license.

| Project | Use |
|---|---|
| [Spine and spine-runtimes](https://github.com/EsotericSoftware/spine-runtimes) | WebGL players. 3.7 from commit `9639bcc`. 3.8 from commit `8b4844b`. 4.x from npm `@esotericsoftware/spine-player`. The Spine Runtimes License applies. |
| [webwallpaper-kde](https://github.com/ekoputrapratama/webwallpaper-kde) | Plugin that shows a web page as the Plasma wallpaper. |
| [Nikke-db](https://github.com/Nikke-db) | Open-source viewer. Studied for skin handling and viewer behavior. |
| [nikke-wallpaper-packs](https://github.com/I6RaVeN9I/nikke-wallpaper-packs) | Public model pack linked from `docs/windows.md` only. Spinewall ships none of it. The pack has no license. The assets belong to SHIFT UP. |
| [Spine-Viewer-Web](https://github.com/FrankoFPM/Spine-Viewer-Web) | Reference for a Spine web viewer. |

Example models for testing come from the Esoteric Software `spine-runtimes` repo.
